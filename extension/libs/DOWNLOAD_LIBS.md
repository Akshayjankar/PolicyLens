# Download Required Libraries

These two files must be downloaded manually before loading the extension:

## html2canvas.min.js
Download from:
https://cdnjs.cloudflare.com/ajax/libs/html2canvas/1.4.1/html2canvas.min.js

Save as: `extension/libs/html2canvas.min.js`

## diff-match-patch.js
Download from:
https://cdnjs.cloudflare.com/ajax/libs/diff_match_patch/20121119/diff_match_patch.js

Save as: `extension/libs/diff-match-patch.js`

## Quick download commands

```bash
curl -L "https://cdnjs.cloudflare.com/ajax/libs/html2canvas/1.4.1/html2canvas.min.js" \
  -o extension/libs/html2canvas.min.js

curl -L "https://cdnjs.cloudflare.com/ajax/libs/diff_match_patch/20121119/diff_match_patch.js" \
  -o extension/libs/diff-match-patch.js
```
